# Что проверено

Проверка: 27 октября 2026 года. После изменения медиа повторите `npm run probe`, после кода — `npm run check` и браузерный тест.

| Область | Проверка | Ограничение |
|---|---|---|
| JS-файл | Воспроизводимая сборка, Acorn ES5, без runtime-зависимостей | Нужны WebView API URL/URLSearchParams |
| Поиск/UI | Unicode, ё/е, год, экранирование | Поиск в выбранном источнике |
| Rezka / Filmix rjson | Схемы по исходникам и фикстуры similar/movie/season/episode/voice/call | Живых разрешённых API/аккаунтов нет; доступ не подтверждён |
| Русская озвучка/сериалы | Тестовый каталог с дубляжом и сериями | Не выдаётся за живой контент Rezka/Filmix |
| MP4/HLS | Контракт Player, подпись MP4, HLS master/media/TS; 1 секунда программного декодирования MP4 и TS | Не тест аппаратного декодирования/звука на TV |
| Резервы | Сеть/5xx, остановка на 401/403/429, конечный перебор ссылок одного качества | Внешний плеер может не поддерживать error callback |
| Настоящая Lampa | Браузерный smoke на закреплённом runtime | Сервисы метаданных отключены, API — фикстуры, Player.play перехватывается |
| Android TV/проекторы | Штатные контроллеры и hover:enter | Физические устройства не подключались |

`npm run check`: 16 тестов, включая загрузку plugin.js в VM с имитацией Lampa/XHR. Проверяются повторный запуск, сохранение экрана при вводе, URL, резервы, доступ, отмена запросов, запуск/возврат плеера. Браузерные скриншоты/отчёт: игнорируемая `test-results/`. Живые HTTP-проверки: [source-checks.json](source-checks.json).

Перед использованием на устройстве:

1. Проверить пункт меню и кнопку в карточке, отсутствие дублей после перезагрузки.
2. Стрелками/OK пройти каталог, озвучку, качество. Проверить Назад и отмену клавиатуры.
3. Запустить демо MP4/HLS: изображение, звук, перемотка, возврат из встроенного/внешнего плеера.
4. Для разрешённого API проверить конкретный фильм/сериал, русскую озвучку, сезон/серию, доступные качества, авторизацию и CORS origin устройства.
5. При недоступной ссылке попробовать ручной резерв. Запрет доступа требует разрешённого входа или прекращения использования.

Нет прямого входа в Rezka/Filmix, произвольных заголовков/токенов, HTML API, автоматического следующего эпизода, общего поиска по всем сервисам, подбора зеркал или публичных прокси. CORS браузер не отличает от части сетевых ошибок, поэтому UI сообщает оба возможных объяснения. Успешный JSON сам по себе не доказывает разрешение интеграции.
