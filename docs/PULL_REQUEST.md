# Add RU Online plugin with remote navigation, authorized API adapters and Pages workflow

Репозиторий содержал только README. Добавлен самостоятельный ES5-плагин стандартной Lampa: поиск в выбранном источнике, кнопка в карточке и боковом меню, озвучки, сезоны/серии, качества, MP4/HLS, ручные резервные ссылки и ограниченный fallback внутри одного качества.

Rezka и Filmix подключаются только через пользовательские разрешённые Lampac rjson endpoints. Нет прямого входа в источники, декодеров, DRM/captcha/geo обходов или предустановленных общих прокси. Открытый каталог Blender позволяет проверять установку без сервера/аккаунта; собственный каталог поддерживает русские озвучки и сериалы.

Сетевые запросы ограничены HTTPS, API-переходы — тем же origin; cookies требуют явного включения. Ошибки 401/403/429 не переключают резервный API. Ответы API не исполняются. Лицензии всех четырёх референсов разобраны в docs/LICENSE-AUDIT.md, код написан заново под MIT.

Validation:

- npm run check: 16 тестов, ES5 и каталог; npm audit: 0 уязвимостей.
- Настоящий yumata/lampa runtime: стрелки/OK/Назад, отмена клавиатуры, каталог, русский сериальный fixture, Rezka/Filmix rjson fixtures, возврат из Player, 1920×1080/1280×720. Player.play перехватывается; это не живое воспроизведение источников.
- HTTPS-проверки MP4 и HLS master/media/TS; FFmpeg декодирует по секунде демо MP4 и TS (H.264/AAC).
- Физических Android TV/проекторов нет. Живые Rezka/Filmix без разрешённого API/аккаунта не проверены.

GitHub Pages workflow публикует public/ после изменения main. CI проверяет сборку и запускает браузерный smoke. Первоначальная удалённая доставка была заблокирована HTTP 403 подключения; актуальное состояние описано в docs/DELIVERY.md.
