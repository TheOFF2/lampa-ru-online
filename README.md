# Lampa RU Online

Плагин для стандартной Lampa: поиск, выбор источника, озвучки, качества, сезонов и серий, MP4/HLS в штатном плеере. Управление: стрелки, OK, Назад. Сборка — один JS без внешних библиотек.

**Статус:** рабочий клиент и открытый демонстрационный каталог. Rezka и Filmix поддерживаются как настраиваемые адаптеры Lampac `rjson`, проверенные на тестовых ответах. **Живое воспроизведение Rezka/Filmix не подтверждено:** разрешённые API и аккаунты для проверки не предоставлены. Плагин не содержит универсального бесплатного сервера этих источников.

## Установка на Android TV / проектор

1. Откройте **Lampa → Настройки → Расширения → Добавить плагин**. В некоторых версиях раздел называется «Плагины».
2. Введите HTTPS-ссылку:

   ```text
   https://theoff2.github.io/lampa-ru-online/ru-online.js
   ```

3. Сохраните и перезапустите Lampa. В боковом меню и карточках появится **RU Online**. Настройки доступны также через **Настройки → RU Online → Открыть RU Online**.
4. Для проверки откройте **RU Online → Открытый тестовый каталог → Синтел → Оригинал → 480p · MP4**. Для HLS: **Большой Бак → Оригинал → Авто HLS**. Это открытые фильмы Blender Foundation, не каталог коммерческих релизов. Русская озвучка в демонстрации не заявляется.

Для установки и демонстрации не нужны компьютер, платный сервер или подписка. Нужны стандартная Lampa с расширениями, интернет, актуальный Android System WebView/Chrome с `URL`/`URLSearchParams`, MP4/H.264/AAC или HLS-совместимый плеер. JS проверяется как ES5; это не гарантия работы на любой старой прошивке. На физических Android TV/проекторах проверки ещё не было.

Страница установки: <https://theoff2.github.io/lampa-ru-online/>. После новой публикации дождитесь завершения GitHub Pages.

## Rezka / Filmix

1. Получите у владельца **разрешённого для вашего использования** API HTTPS-адрес Lampac, поддерживающий `/lite/rezka` или `/lite/filmix` и `rjson=true`.
2. В **RU Online → Настройки источников → Rezka / Filmix — API сервер** укажите базовый адрес: например `https://api.example.org` или `https://api.example.org/lampac`, без `/online.js`, параметров, логина и пароля в URL.
3. Резервный API используется только при недоступности основного: сеть, таймаут, HTTP 5xx. Ответы 401/403/429, HTML входа и несовместимый JSON не вызывают перебор резервов.
4. Если API использует браузерную сессию, выполните разрешённый вход на его сайте и при необходимости включите **Cookies API**. Сервер должен разрешать CORS для origin Lampa; для cookies нужны конкретный origin вместо `*` и `Access-Control-Allow-Credentials: true`. Политика cookies WebView сохраняется. Обязательные произвольные заголовки и токен в базовом URL эта версия не поддерживает.
5. Найдите фильм или откройте кнопку в карточке. Выберите источник, точный результат, озвучку, сезон/серию и качество. Доступны только варианты, действительно возвращённые API. Предпочтительная озвучка поднимает совпадения, не скрывая остальные; качество по умолчанию настраивается отдельно.

**Совместимость с Lampac не доказывает разрешение со стороны Rezka/Filmix.** Проверьте условия источника и право интеграции. В просмотренной документации LampaC есть предупреждение о запрете сторонних Premium-приложений Rezka. Такой доступ не подключайте без разрешения провайдера. Прямой вход в Rezka, парсинг защищённых страниц, расшифровка ссылок, обход капчи, геоблокировок, DRM и подписок не реализованы.

GitHub Pages раздаёт статические файлы: он не исполняет Lampac, не устраняет CORS и не выдаёт доступ к фильмам. Если у источника нет разрешённого браузерного API, универсальный просмотр одним JS без серверной стороны обещать нельзя. Уже доступный разрешённый API можно использовать без собственного компьютера и платного сервера, но его доступность и стоимость определяет владелец. Общие публичные балансеры не предустановлены.

## Свой каталог без сервера

Разместите JSON по HTTPS, например в собственном GitHub Pages, и укажите **Настройки источников → Мой JSON-каталог**. Нужен CORS для Lampa. Можно использовать свои или разрешённые видео, несколько русских озвучек и сериалы. [Формат и пример](docs/API.md). Пароли/персональные токены в публичный каталог не помещайте.

Резервные ссылки выбираются в меню качества. Встроенный плеер при фатальной ошибке может пробовать следующий URL **того же качества** через callback `error`; каждый адрес — один раз. У внешнего Android-плеера callback может отсутствовать: вернитесь и выберите резерв вручную. Другой фильм автоматически не подменяется. Следующая серия выбирается пользователем; автоматический сезонный плейлист пока не реализован.

## Проверки

```sh
npm ci
npm run check
python3 scripts/fetch-lampa.py
npm run test:browser
npm run probe
```

Браузерный тест использует Chromium (`/usr/bin/chromium`, изменить через `CHROMIUM_PATH`). Runtime настоящей Lampa скачивается по фиксированному commit в игнорируемую `.cache` и не распространяется с плагином. Основная проверка `npm run check` не требует браузера/интернета. Если Chromium отсутствует, установите его или используйте `npx playwright install chromium` и передайте путь через `CHROMIUM_PATH`.

- 16 модульных/интеграционных тестов: HTTPS, экранирование, поиск, сериалы, API, доступ, резервы, отмена запросов и запуск/возврат плеера.
- Браузер: настоящий `yumata/lampa@35d79e5e1f256a19862f8cb8dbb79298e5930531`, ответы источников — фикстуры, запуск Player перехватывается. Это не тест декодирования видео.
- Дополнительно: [программное декодирование](docs/media-decode.json) по одной секунде демо MP4 и HLS-сегмента через FFmpeg. Это не проверка на Android TV. Воспроизведение теста: `python3 scripts/decode-demo.py` (нужен FFmpeg).
- Живая сеть: [отчёт о демоссылках](docs/source-checks.json), включая HLS-сегмент. Не гарантия работы на любом устройстве.

## Разработка и публикация

Исходники: `src/`. Сборка: `public/ru-online.js`. `npm run build` воспроизводим; `npm run check` проверяет ES5 и каталог. Дистрибутив не содержит секретов, серверного кода или чужих плагинов. Изменения — через PR; CI проверяет тесты и актуальность сборки.

`.github/workflows/pages.yml` собирает и публикует `public/` после изменения `main` или ручного запуска. В **Settings → Pages → Source** выберите **GitHub Actions**. Первичная версия может публиковаться из `gh-pages`, затем переключаться на Actions с сохранением адресов. Ветки PR автоматически не публикуются.

После обновления перезапустите Lampa/обновите расширение. Если WebView держит старый JS, добавьте `?v=1.0.0` к адресу (при новой версии измените параметр). Каталог кешируется в памяти пять минут, изменение настроек очищает кеш. **Сбросить настройки** затрагивает только RU Online.
